# 🎲 RandStuff: своя последовательность

Chrome-расширение для [RandStuff](https://randstuff.ru/number/), которое позволяет управлять результатами генерации чисел.

Можно заранее задать нужные последовательности, выбрать количество генерируемых чисел и при каждом нажатии «Сгенерировать» подставлять свою последовательность.

## ✨ Возможности

- выбрать количество генерируемых чисел от 1 до 50;
- задавать собственные последовательности;
- одна строка = один результат генерации;
- последовательности автоматически идут по кругу;
- использовать пробелы, запятые или `;` между числами;
- если последовательность короче выбранного количества чисел, подменяется только её начало;
- автоматически устанавливать ползунок RandStuff на нужное количество чисел;
- включать и выключать подмену результатов;
- сохранять настройки между перезагрузками;
- сбрасывать последовательность и начинать с первой строки;
- получать подсказку о том, какая последовательность будет следующей;
- проверять введённые значения перед сохранением.

## 👀 Как это выглядит

В расширении можно выбрать, например:

```text
Генерировать 5 чисел

1 3 3 3 5
2 3 4
5 1 2 4 5
````

При нажатиях на «Сгенерировать» результаты будут:

```text
1 3 3 3 5
2 3 4 ? ?
5 1 2 4 5
1 3 3 3 5
...
```

`?` означает, что соответствующее число не подменяется и остаётся случайным числом RandStuff.

## 🚀 Установка

Расширение устанавливается локально через режим разработчика Chrome.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/buyanchic/randstuff.git
```

### 2. Открыть страницу расширений

В Chrome перейдите:

```text
chrome://extensions
```

### 3. Включить Developer mode

В правом верхнем углу включите:

**Developer mode**

### 4. Загрузить расширение

Нажмите:

**Load unpacked**

и выберите папку проекта.

После этого расширение появится в списке установленных расширений.

## ⚙️ Использование

Откройте:

[https://randstuff.ru/number/](https://randstuff.ru/number/)

Затем нажмите на иконку расширения.

### Количество чисел

В поле «Генерировать» можно указать количество чисел:

```text
1 ... 50
```

Например:

```text
Генерировать 5 чисел
```

При следующем нажатии «Сгенерировать» расширение автоматически выставит ползунок RandStuff на `5`.

### Последовательности

Каждая строка представляет отдельный результат:

```text
1 2 3 4 5
2 3 4 4 5
5 5 1
```

Последовательности используются по порядку:

```text
1 2 3 4 5
↓
2 3 4 4 5
↓
5 5 1
↓
1 2 3 4 5
↓
...
```

### Разделители

Поддерживаются разные варианты записи.

Пробелы:

```text
1 2 3 4 5
```

Запятые:

```text
1, 2, 3, 4, 5
```

Точки с запятой:

```text
1; 2; 3; 4; 5
```

Можно смешивать пробелы и разделители:

```text
1, 2 3; 4 5
```

## 🔢 Последовательность может быть короче

Количество чисел в строке может быть меньше выбранного количества.

Например, если установлено:

```text
Генерировать 5 чисел
```

а последовательность:

```text
1 2 3
```

результат будет:

```text
1 2 3 17 42
```

Первые три числа будут заданными, а оставшиеся два останутся случайными.

При этом указать больше чисел, чем выбрано для генерации, нельзя.

Например:

```text
Генерировать 5 чисел

1 2 3 4 5 6
```

будет отклонено с ошибкой.

## 🔄 Сброс последовательности

Кнопка **«Начать с первой строки»** сбрасывает текущую позицию.

Например:

```text
1 2 3
4 5 6
7 8 9
```

Если текущей была третья строка, после сброса следующей снова станет:

```text
1 2 3
```

## 💾 Сохранение настроек

Настройки сохраняются в `chrome.storage.local`.

После перезагрузки браузера сохраняются:

* количество генерируемых чисел;
* заданные последовательности;
* состояние расширения;
* текущая позиция в списке последовательностей.

Если изменить список последовательностей и сохранить его, расширение автоматически начинает новый цикл с первой строки.

## 🔌 Включение и выключение

Чекбокс **«Расширение включено»** позволяет временно отключить подмену.

Когда расширение выключено, RandStuff работает в обычном режиме.

При повторном включении заданные последовательности сохраняются.

## 🧩 Как это работает

Расширение состоит из popup-интерфейса и content script.

```text
┌─────────────────────┐
│      popup.html     │
│                     │
│  Количество: 5      │
│  1 2 3 4 5          │
│  2 3 4 4 5          │
│                     │
│      Сохранить      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ chrome.storage.local│
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     content.js      │
│                     │
│  → ловит клик       │
│  → двигает ползунок │
│  → ждёт результат   │
│  → подменяет числа  │
└─────────────────────┘
```

`content.js` работает непосредственно на странице RandStuff.

После нажатия кнопки:

1. берётся текущее количество чисел;
2. ползунок RandStuff устанавливается на это значение;
3. выбирается следующая последовательность;
4. запускается обычная генерация RandStuff;
5. `MutationObserver` отслеживает изменение результата;
6. заданные числа подставляются в результат;
7. остальные числа остаются случайными, если последовательность короче выбранного количества.

## 📁 Структура проекта

```text
randstuff/
├── icons/
│   ├── icon16.png
│   ├── icon32.png
│   ├── icon48.png
│   └── icon128.png
│
├── content.js
├── popup.html
├── popup.js
├── shared.js
└── manifest.json
```

### `manifest.json`

Конфигурация Chrome-расширения:

* Manifest V3;
* permissions;
* popup;
* иконки;
* страницы, на которых запускается content script.

### `popup.html`

Интерфейс расширения:

* выбор количества чисел;
* ввод последовательностей;
* включение и выключение;
* сохранение;
* сброс последовательности.

### `popup.js`

Отвечает за:

* работу интерфейса;
* изменение количества чисел;
* валидацию;
* сохранение настроек;
* отображение следующей последовательности.

### `content.js`

Основная логика на странице RandStuff:

* обработка нажатия «Сгенерировать»;
* управление ползунком;
* поиск результатов;
* подмена заданных чисел;
* отслеживание изменений DOM.

### `shared.js`

Общие настройки и функции:

* значения по умолчанию;
* ограничение количества чисел;
* парсинг последовательностей;
* валидация.

## 🔐 Разрешения

Расширение использует только:

```json
"permissions": ["storage"]
```

Разрешение `storage` необходимо для сохранения пользовательских настроек.

Content script запускается только на:

```text
https://randstuff.ru/number/*
```

## ⚠️ Ограничения

Расширение зависит от текущей структуры страницы RandStuff.

Если сайт изменит:

* HTML-разметку;
* ID элементов;
* кнопку генерации;
* работу ползунка;
* способ отображения результатов;

расширение может перестать корректно работать и потребовать обновления.
