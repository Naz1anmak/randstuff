# 🎲 RandStuff: своя последовательность

Расширение для Chrome и Яндекс Браузера (подойдёт и другой браузер на Chromium) для [RandStuff](https://randstuff.ru/number/), которое позволяет управлять результатами генерации чисел.

Можно заранее задать нужные последовательности, выбрать количество генерируемых чисел и при каждом нажатии «Сгенерировать» подставлять свою последовательность.

Основано на расширении [buyanchic](https://github.com/buyanchic).

## ✨ Возможности

- выбрать количество генерируемых чисел от 1 до 50;
- задавать собственные последовательности;
- одна строка = один результат генерации;
- последовательности идут по кругу или один раз, после чего числа становятся настоящими;
- использовать пробелы, запятые или `;` между числами;
- если последовательность короче выбранного количества чисел, подменяется только её начало;
- автоматически устанавливать ползунок RandStuff на нужное количество чисел;
- включать и выключать подмену горячей клавишей (её можно переназначить прямо в попапе);
- учитывать ограничения сайта: диапазон, список и исключённые числа;
- видеть номера строк и то, какая строка сейчас на сайте;
- сохранять настройки между перезагрузками;
- сбрасывать последовательность и начинать с первой строки;
- получать подсказку о том, какая последовательность будет следующей;
- проверять введённые значения перед сохранением.

## 👀 Как это выглядит

В расширении можно выбрать, например:

```text
Генерировать 5 чисел

1 3 3 3 5
2 3 4
5 1 2 4 5
```

При нажатиях на «Сгенерировать» результаты будут:

```text
1 3 3 3 5
2 3 4 ? ?
5 1 2 4 5
1 3 3 3 5
...
```

`?` означает, что соответствующее число не подменяется и остаётся случайным числом RandStuff.

## 🚀 Установка

Расширение устанавливается локально через режим разработчика.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Naz1anmak/randstuff.git
```

### 2. Открыть страницу расширений

В Chrome перейдите:

```text
chrome://extensions
```

В Яндекс Браузере:

```text
browser://extensions
```

### 3. Включить режим разработчика

В правом верхнем углу включите **Developer mode** («Режим разработчика»).

### 4. Загрузить расширение

Нажмите **Load unpacked** («Загрузить распакованное расширение») и выберите папку проекта.

После этого расширение появится в списке установленных расширений.

## ⚙️ Использование

Откройте:

[https://randstuff.ru/number/](https://randstuff.ru/number/)

Затем нажмите на иконку расширения.

### Количество чисел

В поле «Генерировать» можно указать количество чисел:

```text
1 ... 50
```

Например:

```text
Генерировать 5 чисел
```

При следующем нажатии «Сгенерировать» расширение автоматически выставит ползунок RandStuff на `5`.

### Последовательности

Каждая строка представляет отдельный результат:

```text
1 2 3 4 5
2 3 4 4 5
5 5 1
```

Последовательности используются по порядку:

```text
1 2 3 4 5
↓
2 3 4 4 5
↓
5 5 1
↓
1 2 3 4 5
↓
...
```

Слева от поля показаны номера строк. Жёлтым подсвечен номер строки, числа из которой сейчас на сайте, а под кнопкой «Сохранить» написано, что выпадет следующим нажатием.

### По кругу или один раз

Галочка **«Повторять по кругу»** включена по умолчанию: после последней строки список начинается заново.

Если её снять, список пройдёт один раз, а дальше RandStuff будет выдавать настоящие случайные числа:

```text
1 2 3 4 5
↓
2 3 4 4 5
↓
5 5 1
↓
настоящие числа
```

Кнопка **«С первой строки»** запускает список заново.

### Разделители

Поддерживаются разные варианты записи.

Пробелы:

```text
1 2 3 4 5
```

Запятые:

```text
1, 2, 3, 4, 5
```

Точки с запятой:

```text
1; 2; 3; 4; 5
```

Можно смешивать пробелы и разделители:

```text
1, 2 3; 4 5
```

## 🔢 Последовательность может быть короче

Количество чисел в строке может быть меньше выбранного количества.

Например, если установлено:

```text
Генерировать 5 чисел
```

а последовательность:

```text
1 2 3
```

результат будет:

```text
1 2 3 17 42
```

Первые три числа будут заданными, а оставшиеся два останутся случайными.

При этом указать больше чисел, чем выбрано для генерации, нельзя.

Например:

```text
Генерировать 5 чисел

1 2 3 4 5 6
```

будет отклонено с ошибкой.

## 🎯 Ограничения сайта

Расширение читает настройки RandStuff и не подставляет число, которое сайт выдать не может:

* число вне диапазона «от … до»;
* число, которого нет в списке, если выбран режим «из списка»;
* число из списка «исключить числа».

На месте такого числа остаётся настоящее случайное число RandStuff, а в попапе вместо него показывается `?`.

Например, при диапазоне от 1 до 17:

```text
18    →    ? (выпадет настоящее число от 1 до 17)
```

## 🔄 Сброс последовательности

Кнопка **«С первой строки»** сбрасывает текущую позицию.

Например:

```text
1 2 3
4 5 6
7 8 9
```

Если текущей была третья строка, после сброса следующей снова станет:

```text
1 2 3
```

## 💾 Сохранение настроек

Настройки сохраняются в `chrome.storage.local`.

После перезагрузки браузера сохраняются:

* количество генерируемых чисел;
* заданные последовательности;
* включена ли подмена и повторять ли список по кругу;
* горячая клавиша;
* текущая позиция в списке последовательностей.

Если изменить список последовательностей и сохранить его, расширение автоматически начинает новый цикл с первой строки.

## 🔌 Включение и выключение

Подмена включается и выключается горячей клавишей на странице RandStuff:

| Система | По умолчанию |
|---|---|
| macOS | `⇧⌘Y` |
| Windows / Linux | `Ctrl+Shift+Y` |

Чтобы задать своё сочетание, нажмите на поле с сочетанием в попапе и нажмите нужные клавиши. Нужен хотя бы один модификатор (`⌘`, `⌥`, `⌃` или `Ctrl`, `Alt`), `Esc` отменяет запись.

Пока подмена выключена, на иконке расширения виден значок **OFF**, а RandStuff работает в обычном режиме. Заданные последовательности при этом сохраняются.

Клавиша работает, когда открыта вкладка RandStuff. Сочетания, занятые самим браузером, до страницы не доходят — такие лучше не выбирать.

## 🧩 Как это работает

Расширение состоит из popup-интерфейса и content script.

```text
┌─────────────────────┐
│      popup.html     │
│                     │
│  Количество: 5      │
│  1 2 3 4 5          │
│  2 3 4 4 5          │
│                     │
│      Сохранить      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ chrome.storage.local│
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     content.js      │
│                     │
│  → ловит клик       │
│  → двигает ползунок │
│  → ждёт результат   │
│  → подменяет числа  │
└─────────────────────┘
```

`content.js` работает непосредственно на странице RandStuff.

После нажатия кнопки:

1. берётся текущее количество чисел;
2. ползунок RandStuff устанавливается на это значение;
3. выбирается следующая последовательность;
4. запускается обычная генерация RandStuff;
5. `MutationObserver` отслеживает изменение результата;
6. заданные числа подставляются в результат;
7. остальные числа остаются случайными, если последовательность короче выбранного количества.

## 📁 Структура проекта

```text
randstuff/
├── icons/
│   ├── icon16.png
│   ├── icon32.png
│   ├── icon48.png
│   └── icon128.png
│
├── background.js
├── content.js
├── popup.html
├── popup.js
├── shared.js
└── manifest.json
```

### `manifest.json`

Конфигурация Chrome-расширения:

* Manifest V3;
* permissions;
* popup;
* фоновый скрипт;
* иконки;
* страницы, на которых запускается content script.

### `background.js`

Показывает значок **OFF** на иконке, пока подмена выключена.

### `popup.html`

Интерфейс расширения:

* выбор количества чисел;
* ввод последовательностей с номерами строк;
* режим «по кругу» или один раз;
* поле горячей клавиши;
* сохранение;
* сброс последовательности.

### `popup.js`

Отвечает за:

* работу интерфейса;
* изменение количества чисел;
* валидацию;
* сохранение настроек;
* запись горячей клавиши;
* номера строк и подсветку текущей строки;
* отображение следующей последовательности.

### `content.js`

Основная логика на странице RandStuff:

* обработка нажатия «Сгенерировать»;
* управление ползунком;
* поиск результатов;
* подмена заданных чисел;
* чтение ограничений сайта (диапазон, список, исключения);
* горячая клавиша вкл/выкл;
* отслеживание изменений DOM.

### `shared.js`

Общие настройки и функции:

* значения по умолчанию;
* ограничение количества чисел;
* парсинг последовательностей;
* валидация;
* проверка чисел по ограничениям сайта;
* горячая клавиша: сочетание по умолчанию и подпись для macOS / Windows.

## 🔐 Разрешения

Расширение использует только:

```json
"permissions": ["storage"]
```

Разрешение `storage` необходимо для сохранения пользовательских настроек.

Content script запускается только на:

```text
https://randstuff.ru/number/*
```

## ⚠️ Ограничения

Расширение зависит от текущей структуры страницы RandStuff.

Если сайт изменит:

* HTML-разметку;
* ID элементов;
* кнопку генерации;
* работу ползунка;
* способ отображения результатов;

расширение может перестать корректно работать и потребовать обновления.
