# 🎲 RandStuff: своя последовательность

Расширение для Chrome и Яндекс Браузера (подойдёт и другой браузер на Chromium), которое подставляет на [RandStuff](https://randstuff.ru/number/) ваши числа вместо случайных.

## ✨ Возможности

- свои последовательности: одна строка — одно нажатие «Сгенерировать»;
- список по кругу или один раз, после чего числа становятся настоящими;
- горячая клавиша вкл/выкл подмены, её можно переназначить прямо в попапе;
- учёт настроек сайта: количество чисел, диапазон, список, исключённые числа и повторы;
- номера строк, подсветка текущей строки и подсказка, что выпадет следующим;
- проверка списка прямо при вводе.

## 🚀 Установка

1. Скачайте `randstuff.zip` из [последнего релиза](https://github.com/Naz1anmak/randstuff/releases/latest) и распакуйте его.
   Или склонируйте репозиторий: `git clone https://github.com/Naz1anmak/randstuff.git`
2. Откройте страницу расширений: `chrome://extensions` в Chrome или `browser://extensions` в Яндекс Браузере.
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку с расширением.

## ⚙️ Использование

Откройте [randstuff.ru/number](https://randstuff.ru/number/), нажмите на иконку расширения и впишите последовательности:

```text
1 3 3 3 5
2 3 4
5 1 2 4 5
```

При нажатиях «Сгенерировать» на сайте выпадет:

```text
1 3 3 3 5
2 3 4 ? ?
5 1 2 4 5
```

`?` — число не подменяется и остаётся настоящим случайным числом RandStuff.

- **Количество чисел** задаёт ползунок на сайте. Если в строке чисел меньше, остальные будут случайными; если в расширении выбрано другое количество, попап подскажет.
- **Разделители** — пробел, запятая или `;`. Если генерируется одно число, строка `1,2,3` при сохранении сама разнесётся по отдельным строкам.
- **По кругу.** С галочкой «Повторять по кругу» список начинается заново, без неё после последней строки числа настоящие. Кнопка «С первой строки» запускает список сначала.
- **Ограничения сайта.** Число вне диапазона «от … до», не из списка, из исключённых или повтор при «исключить повторения» не подставляется — на его месте выпадет настоящее, а в попапе будет `?`.

## 🔌 Горячая клавиша

Включает и выключает подмену на вкладке RandStuff:

| Система | По умолчанию |
|---|---|
| macOS | `⇧⌘Y` |
| Windows / Linux | `Ctrl+Shift+Y` |

Чтобы задать своё сочетание, нажмите на поле с сочетанием в попапе и нажмите клавиши (нужен `⌘`, `⌥`, `⌃` или `Ctrl`, `Alt`; `Esc` — отмена). Пока подмена выключена, на иконке виден значок **OFF**. Сочетания, занятые самим браузером, до страницы не доходят.

## 🔐 Разрешения

Только `storage` — для сохранения настроек. Расширение работает только на `https://randstuff.ru/number/*`.

## ⚠️ Ограничения

Расширение зависит от разметки RandStuff: если сайт её поменяет, расширение может перестать работать.
